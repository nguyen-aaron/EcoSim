# 🌿 EcoSim: Interactive Ecosystem Simulator

EcoSim is a webapp that runs custom simulations of various species dynamics in ecological systems.

The app is built in React and Python.

## Features

- **Real-time simulation of generic ecosystem models**
    -  Representations of ecosystem populations over time using Lokta-Volterra Predator-Prey and Competition mathematical models.
    - Custom-built charting system, allowing lightweight rendering and smooth live updates.
    - Hot-swappable parameter editing.
    - Soon: Data capturing and downloading of data in a `.csv` file, and summaries of a simulation run. 

- Soon: **In-depth species-specific simulations using [Project Mesa](https://github.com/projectmesa/mesa)** 
    - Real-time simulations of individual species using a grid representation of food and animal populations

## Project Setup & Development

Run locally: `npm start`

Build for production: `npm run build`

### Requirements:
- Node.js 16 or higher
- npm 8 or higher
- npm install react-katex katex
- install packages in requirements.txt
